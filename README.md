## Project Title
**Dojo Weather – Interactive Weather Forecast Page**

## Short GitHub Description
A responsive weather forecast webpage built with HTML, CSS, and JavaScript. It displays weather predictions for several days and allows users to switch between Celsius and Fahrenheit.

## Detailed Description
Dojo Weather is a simple and interactive weather forecast interface that shows weather conditions and temperatures for four days. The page is designed with a clean layout and allows users to convert temperatures between Celsius and Fahrenheit.

It also includes a city navigation menu, alert messages when selecting a city, and a cookie notification that can be hidden after the user accepts it.

### Features
- Weather forecast cards for four days
- Weather icons and descriptions
- High and low temperature display
- Celsius/Fahrenheit temperature conversion
- Interactive city navigation links
- Cookie notification that can be dismissed
- Responsive layout using CSS Flexbox

### Technologies Used
- HTML5
- CSS3
- JavaScript

### Note
The current weather data is static and does not use a live weather API.
